# 种源微生物：概念、关键知识点与前沿研究

> 整理日期：2026-08-25（老师课堂讲解 + 学习整理）

## 一、什么是种源微生物

**种源微生物（Seed-borne / Seed-associated Microbes）**：栖居在种子上或种子内部的微生物（细菌、真菌、病毒等）。种子是植物'种'最直接传承的载体，微生物也跟着种子代代相传，所以叫"种源微生物"。

## 二、六大核心知识点

### 1. 按位置分类（理解"内部"二字的关键）
- **附生菌**：待在种子表面，容易洗掉
- **内生菌**（研究重点）：住在种皮、种胚内部，**表面消毒也杀不掉**。要分离内部菌，必须先给种子做表面消毒（75% 乙醇 + 2% 次氯酸钠浸泡 + 无菌水漂洗），再研磨或整粒接种

### 2. 来源
多数从母株、田间环境、土壤、花粉传入，属于**垂直传播**（亲代 → 种子 → 子代）。

### 3. 研究意义（三大类）
- **有益**：分泌促生物质、抑制病原菌、增强种子抗逆、帮助幼苗早期定植（相当于"种子自带的益生菌"）
- **有害**：部分就是种传病原菌，是植物病害远距离传播的重要途径
- **应用价值**：开发生物菌剂 / 生物农药，减少化学药剂使用

### 4. "起点"为什么重要（种子微生物组 = 下一代植物微生物组的起点）
- **定植优先权**：先到得先，种子里的菌比土壤菌早几个月住下，早期微生物抢占生态位，基本决定整株植物菌群大格局
- **亲代经验传承**：母株若遭遇病害、干旱，会把"有经验"的菌群传给种子，好比妈妈把抗体传给孩子
- **应用价值**：干预成本最低——一次种子处理（包衣、蘸菌）等于把菌塞进起跑线，全株收益

### 5. 与土壤微生物组的关系
种子微生物是植物一生微生物组的"第一桶金"，之后才与土壤中的微生物汇合。

### 6. 为什么用"分离培养"来研究
先要把单一菌种提出来，才能鉴定它是谁（形态 / DNA）、有什么用（功能验证），固体与液体培养基就是为这一步准备的。

## 三、概念升级：从"种子微生物"到"种子微生物组"

- 单个微生物 = 研究村子里的一两个人；微生物组 = 研究整个村子的关系网
- 很多作用需要整个菌群配合才出现，因此研究方法升级为高通量测序，对种子内所有微生物 DNA 整体普查

## 四、种子表面的生物膜与"发霉"生存策略

### 生物膜（Biofilm）
微生物聚在一起分泌"胶水"（胞外聚合物 EPS），形成带围墙的合作社区——种子表面的菌群组织。

三大作用：

| 功能 | 通俗理解 |
| --- | --- |
| 休眠维持 | 膜内微生物产出抑制萌发物质，告诉种子：环境不适合，先睡着 |
| 免疫守卫 | 物理+化学双屏障，分泌拮抗物质，把病原菌挡在门外 |
| 低活跃防御 | 压低种子代谢，省能耗活，扛过恶劣环境 |

### 种子发霉 = 生存策略
- 种子表面"霉"（附生真菌）在恶劣环境下把种子包起来：保湿防失水、隔离真病原菌、抑制种子提前萌发
- 本质是**牺牲现在、保住后代**——发霉的种子有时反而最先挨过难关

## 五、与"人"类比：顺产 vs 剖腹产

- **顺产**：经过产道，全身涂上乳酸杆菌（产道自带益生菌），第一口菌群正确 → 起点好
- **剖腹产**：跳过产道，先接触医院环境菌群（葡萄球菌、大肠杆菌等），乳酸杆菌少，部分研究显示过敏/哮喘/肥胖风险略高（存在争议）
- **结论**：起点重要，但菌群一生都在变化，可后天弥补（母乳、辅食、产道菌液涂抹等）
- **对应植物**：种子出生菌 = 植物一生的"出厂底色"，但土壤后天的补充同样重要

## 六、必须记住的重点（考试 / 答辩高频）

1. **休眠不全是种子的事**：ABA（刹车）与 GA（油门）对抗，微生物会掺和——产生抑制物质、抢糖分，帮种子踩刹车
2. **种子保质期与菌群有关**：内生菌助抗氧、防霉变，菌群好 = 种子耐储藏
3. **"种传病害"与"种源保护"是一对矛盾**：同一层菌既有功臣也有叛徒，分离培养的意义是把好的挑出来

## 七、前沿研究动态

1. **合成微生物群落（SynCom）**：把种子天然核心菌"配方"抄下来，人工配一个菌团包给种子，比单株菌剂更强，目前最火
2. **跨代记忆**：母株受旱、受病后，种子菌群会"记住"并传承，是植物适应气候变化（应急）的隐藏大招
3. **培养组学（Culturomics）**：传统分离培养与高通量测序结合，把种子里的菌彻底挖出来——TSB 分离培养正是这个前沿技术的入门功夫

## 八、一句话串起全流程

> 母株把微生物传给种子 → 多藏在种子内部 → 表面消毒去掉表面的 → 内部打碎/接种 → TSB 培养基喂它们 → 分离出纯单菌落 → 鉴定并验证功能
