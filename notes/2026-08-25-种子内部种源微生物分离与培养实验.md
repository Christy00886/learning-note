# 种子内部种源微生物分离与培养 实验记录

> 日期：2026-08-19（实验）；记录整理：2026-08-25
> 操作人：hzq（A组第2位成员）

## 一、实验背景

从种子样品内部分离培养种源微生物（内生菌），为后续菌种鉴定与功能研究做准备。整体思路：表面消毒 → 内部菌源分离 → 培养基培养 → 纯化单菌落。

## 二、上午：固液态培养基配制 + 高温灭菌

### （一）TSB 培养基配制

| 类型 | 配制方法 |
| --- | --- |
| 液体 TSB | 按瓶身配方比例（g/L）加入蒸馏水稀释配制 |
| 固体 TSB | 在液体培养基基础上，额外加入 1% 琼脂（本次加入 **5 g**，对应约 500 mL 液体，即 1%） |

- 配好后装瓶（一般留约 1/3 空间，防止灭菌时液体溢出）

### （二）高温灭菌（P3 程序）

- **灭菌对象**：配好的培养液与移液枪头等实验物品**一起一锅灭菌**
- **程序选择 P3（液体模式）的原因**：锅内有液体培养基，必须选择**慢排气**的液体程序；若用 P4（器械/固体模式，快排气），液体可能瞬间沸腾、冲开瓶盖、培养基喷出。移液枪头等物品耐 121℃ 高温，跟随液体程序灭菌无影响
- **温度与时长**：121℃，时长常见 20 分钟（待回忆确认 15/20/30）

## 三、下午：倒平板

培养基降温至约 45~50℃（手背碰瓶身不烫、未凝固），在无菌条件下倒入培养皿：

1. **培养皿提前灭菌**：最好与培养基同锅灭菌，省事且保证无菌
2. **无菌操作**：超净工作台提前开紫外照射 15~30 min，再开风机吹 5 min；操作靠近酒精灯，瓶口过火
3. **每皿倒 15~20 mL**（90 mm 皿），薄薄铺满均匀即可，勿倒太厚
4. **倒完静置凝固**，勿再移动触碰（琼脂数分钟内成"果冻"状）
5. **凝固后倒扣（盖朝下）**，防止盖子冷凝水滴回培养基污染
6. **先验证无菌**：37℃ 培养 24 h，无杂菌长出即为合格平板，合格后才用于后续接种

## 四、种子表面消毒与制菌悬液

**表面消毒（超净台内）：**
1. 蒸馏水冲洗：洗掉表面灰尘杂质
2. **2% 次氯酸钠浸泡 5 min**：杀灭表面微生物（次氯酸 = 强氧化剂，漂白杀菌）
3. **75% 乙醇浸泡 30 s**：双保险快刀消毒
4. **无菌水冲洗 3~5 次**：洗掉残留消毒剂

**研磨制匀浆：**
5. 研钵（提前高压灭菌）研磨消毒后的种子 → 先加少量无菌水润磨，磨成细腻浆状 → 补足 **5 mL 无菌蒸馏水** → 制成匀浆菌悬液（此为原液）

**注意点：**
- 时间要严格：乙醇浸泡超时会渗进种子杀掉内部菌（假阴性）；浸泡不足表面菌残留（假阳性）
- 冲洗 3~5 次不能省，残留 NaClO 会在研磨后继续"下毒"
- 建议设置对照：最后一次洗液涂一块平板，无菌长出 = 表面消毒彻底

## 六、平板标签命名规范

格式：**组名+成员序号+种源编号+重复号 + 日期 + 姓名缩写**

示例：`A2M2R1 8.19 hzq`

| 字段 | 含义 |
| --- | --- |
| A2 | A组第2位成员 |
| M2 | 第2种玉米种子（种源编号） |

**注意**：另起一行补充**稀释倍数 + 涂布量**（例：稀释 10^-1，涂布 100 μL），避免数据丢失。

## 七、培养箱培养注意事项

1. **温度**：种子内生菌多喜常温，分离培养建议 **28~30℃**；37℃ 仅用于平板无菌质检
2. **倒扣放置**：涂布后先正置 30 min（菌液吸收），再倒扣入箱；倒扣防止冷凝水滴回培养基
3. **摆放**：不堵气流、不堆太高、避开出风口直吹
4. **保湿**：3~7 天长期培养需封口膜封边，箱底可放水盘
5. **观察时间表**：第 1、2、3 天每天看，之后隔 1~2 天；内生菌最长需 7~14 天，勿提前判死刑
6. **识别污染**：绒毛状/棉花团 = 霉菌；水汪汪蔓延 = 涂布棒或超净台污染；大范围污染需排查培养基、灭菌、超净台
7. **日常**：减少开关门、定时看温湿度计、平板标签齐全

## 八、实验复盘（第一次结果：菌没长）

**可能原因**：
1. 直接涂原液导致淀粉堆积、菌落被覆盖看不清
2. 稀释倍数未知，若稀释过度（10^-4 以上），内生菌数量降至个位数
3. 表面消毒时间偏长，内部菌受损
4. 培养时间不足（内生菌生长慢）
5. 营养不对口：TSB 为细菌培养基，若种子内主要是真菌则不长

**改进方案**：
1. 多个稀释度平行涂布（原液、10^-1、10^-2、10^-3），选菌落数 30~300 的板计数
2. 记录本上固定记录稀释倍数
3. 同时做液体 TSB 富集备份（摇床 3~5 天），确认菌是否存活
4. 延长培养观察至 7 天

## 九、新实验：土壤浸出液中细菌的培养

种子内菌未长出后，改用三种土壤浸出液作为菌源筛选可培养细菌。

### 材料
- 3 种土壤浸出液：**7-1、7-2、7-3**（土种信息待向师兄确认）
- 此前备好的 TSB 固体平板

### 实验流程
1. 准备：超净台紫外 15~30 min → 风机吹 5 min；平板开盖吹 5~10 min 至表面微干；涂布棒蘸 75% 乙醇过火，冷却 10 s
2. 取液：每个浸出液瓶子先摇匀（菌可能沉淀），无菌枪头取 100 μL，悬空滴在平板靠边（浸出液若太浓则先梯度稀释）
3. 涂布：每种浸出液涂 **3 个平板（= 3 个重复）**；从稀到浓、轻折转涂匀、换板必过火
4. 标记：`7-1R1 / 7-1R2 / 7-1R3  8.19  hzq`，另记录稀释倍数
5. 培养：倒扣，28℃ 恒温培养 24~72 h，每天查看
6. 观察计数：菌落数 30~300/板为宜；记录菌落形态（颜色、大小、边缘、是否黏液），三种浸出液横向对比
7. 后续：挑取典型单菌落 → 划线纯化 → 镜检/保藏/鉴定
