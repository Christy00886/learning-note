# 土壤 pH 与 Eh 结果分析：统计流程与高水平论文写法

> 整理日期：2026-08-29

拿到一组土壤 pH / Eh 数据之后，从整理到汇报的完整流程。每一步都有明确的统计目的，写法对标高水平论文。

## Q1：拿到数据，第一件事做什么？

把原始数据整理成「处理 × 重复」两维表（每个处理 3~4 个独立重复），先算 mean ± SD，画图时常用 mean ± SE。

- 目的一：检查数据——有无异常值、缺测、单位混淆
- 目的二：确认重复有效——真正的生物学重复（3 盆土 / 3 个采样点），不是同一样品测 3 次（那是技术重复，只能求均值，不能做统计推断）
- 目的三：得到代表值，为后面一切铺垫

高水平论文的做法：结果表直接放 mean ± SD 和 n；「每个处理 4 个生物学重复」写进材料方法。

## Q2：为什么还要先做「前提检验」？

ANOVA 有三个前提：各组正态分布、各组方差齐、数据独立。前两个要检验：

- 正态性：Shapiro-Wilk（小样本首选；SPSS 路径：分析 → 描述统计 → 探索）
- 方差齐性：Levene（单因素 ANOVA 对话框 → 选项 → 勾「方差齐性检验」）

目的：决定路线——满足前提走参数方法（ANOVA + Tukey），不满足走非参数（Kruskal-Wallis + Dunn）。

这句话要写进论文方法部分，例：Data were checked for normality (Shapiro-Wilk) and homogeneity of variance (Levene) before ANOVA. 审稿人很在意这个。

## Q3：为什么不能直接两两 t 检验，必须先 ANOVA？

因为「假阳性累积」：每次比较都自带 5% 出错率，3 个处理两两比 3 次，整体出错率升到约 14%——你的「显著差异」可能只是运气。

- ANOVA 的 F 检验回答总问题：处理之间整体上有没有差异？
- 事后多重比较回答局部问题：差异具体在哪两个处理之间？
- 顺序永远是：先整体（控制错误率）→ 后局部（校正后比较）

## Q4：ANOVA 怎么做？结果怎么报？

SPSS：分析 → 比较平均值 → 单因素 ANOVA → 处理放「因子」，pH（或 Eh）放「因变量」，选项中勾「描述统计」，用「事后比较」勾 Tukey。

看：ANOVA 表中的 F 值和 P（Sig.）。报告格式：F(处理自由度, 误差自由度) = 8.56, P < 0.001。5 个处理 = F(4, 误差df)。

提醒：如果实验有多个因素（处理 × 时间 / 肥料 × 水分），要用双因素 ANOVA 或重复测量方差分析，别硬套单因素——交互作用会被吞掉。

## Q5：多重比较怎么选？为什么优先 Tukey？

Tukey HSD 是「校正过的两两比较」：既维持整体置信水平，又告诉你哪两对有差异。

- Fisher LSD：不校正、最宽松，快但易假阳性，最常被审稿人点名
- Duncan：折中方案，很多中文论文用
- Tukey HSD：保守、标准，国际期刊默认
- Dunnett：只和对照比，适合「每个处理 vs CK」的实验

字母规则：同一列内字母相同 = 差异不显著，字母不同 = 显著（a、b、c 的排序只表示统计分组）。方法部分要写明：Multiple comparisons were performed using Tukey's HSD test at P < 0.05.

## Q6：数据不正态 / 方差不齐怎么办？

三条路：

- Kruskal-Wallis H 检验（非参数版「ANOVA」）+ 事后 Dunn 检验（带 Bonferroni 校正）
- 数据转换：偏态数据 log 或平方根；比例数据反正弦。分析基于转换后数据要在方法里说明
- 方差不齐但样本均衡 → Welch ANOVA + Games-Howell

写作细节：报告 P 值写准确值（P = 0.048），比一律 P < 0.05 信息量大。

## Q7：pH 和 Eh 要不要结合起来分析？（加分项）

要。两者在氧化还原化学中强耦合：常温下 pH 每升 1 个单位，Eh 理论上约降 59 mV（Nernst 方程）。微生物的硝化、Fe(III) 还原、产甲烷等活动会同时改写 pH 和 Eh。

高水平论文做三件事：

- 各自单因素分析 + 多重比较
- pH–Eh 散点图 + Pearson 相关（非正态用 Spearman），报 r 与 P
- 进阶：协方差分析（ANCOVA）或偏相关——把 pH 当协变量，判断处理的 Eh 效应是「直接的」还是「通过改 pH 间接带来的」。校正 pH 后差异仍显著 = 直接效应；变不显著 = pH 是中介

能把这个循环写进讨论，就是比同行多想一步。

## Q8：图怎么画才像高水平论文？

主流：带原始散点的柱状图或箱线图 + 显著性字母 + 误差线。

- 柱子 = mean；误差线 = SE（图注必须写清 SD/SE 和 n）
- 每个重复画在柱子上（jitter 散点）
- 组上方标字母（同一样式、同字号）
- pH、Eh 各一幅，或上下两面板拼成一幅（a / b）

避雷：

- 三维柱状图、渐变色柱状图——丑且带误导
- 截断 y 轴放大差异——学术雷区
- 图注要「自明」：误差线类型 + n + 统计方法 + P 阈值写全，读者不看正文能看懂
- 300 dpi 以上 / 矢量图；色弱友好配色
- pH 波动很小的数据（±0.1~0.2 之内）别硬截轴；图上看不出差距就靠文字 + P 值说明，同样是严谨结果

表格：三线表（处理 | mean ± SD | 字母），加一列 F 和 P 更完整；原始数据放附表或补充材料。

## Q9：结果与讨论怎么写？

结果三段式：

- 整体：处理间有无显著差异、变幅多大、谁最大谁最小
- 证据：F、P、字母、n，并引用图/表
- 定位：哪些处理对显著，差异多少（0.15 个 pH 单位 / 多少 mV）

模板：

「不同处理对土壤 pH 有显著影响（F(4,10) = 8.56, P < 0.001）；T2 显著低于 CK（P < 0.05，图 a），其余处理与 CK 差异不显著（P > 0.05）。」

「处理间 Eh 差异不显著（F(4,10) = 1.24, P = 0.356）；但 pH–Eh 呈显著负相关（r = −0.78, P = 0.002，图 b），提示 Eh 变化与 pH 耦联。」

讨论别复述结果，回答「为什么」：

- 哪一步的处理设计解释了这个趋势？（施肥 / 有机质 / 灌水 / 微生物作用）
- 与已有研究一致还是不一致（引文献）
- 提出机制解释后给证据（相关性、文献、或设计本身）
- 结尾一句：本结果支持 / 不支持 XX 假说

## Q10：常见坑

- 生物学重复 ≠ 技术重复，n=3 必须是 3 个独立个体/采样单元
- 跳着做 ANOVA 不报前提检验 → 审稿人必问
- 多重比较不注明方法（LSD 不校正、Tukey 混用）
- 图注缺 n、缺误差线类型
- 只报 P 不报幅度：P < 0.001 但只差 0.02 个 pH 单位，生物意义要单独讨论
- P > 0.05 的结果也要如实放——「无显著差异」是有价值的信息
- 审稿人视角自查：方法部分能否复现（软件、版本、函数、α 值）

## Q11：新手行动清单

1. 整理数据表，算 mean ± SD，查异常
2. Shapiro-Wilk + Levene
3. 满足 → 单因素 ANOVA；不满足 → Kruskal-Wallis
4. Tukey HSD → 字母分组
5. pH–Eh 散点 + 相关分析（可选 ANCOVA）
6. 图（柱子 + 散点 + 字母）+ 三线表
7. 结果三段式 + 讨论「为什么」

工具：SPSS 够用；R 的 agricolae 包一步给出 ANOVA + Tukey + 字母；Python 的 scipy.stats 也能做（f_oneway + tukey_hsd）；GraphPad Prism 出图最漂亮。

附 Python 一行流：

```python
from scipy import stats
F, P = stats.f_oneway(pH_CK, pH_T1, pH_T2)   # ANOVA
res = stats.tukey_hsd(pH_CK, pH_T1, pH_T2)   # Tukey 两两比较
```
